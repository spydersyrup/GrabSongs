# CassetteCat Button & UI Styling Rule

1. **TransportButton Component Style**:
   - The authentic CassetteCat button style is the tactile outline `TransportButton.qml` with a subtle circular outline border (`border.width: 1.2`), transparent/glass background, red outline accent when `accented: true`, and red icon.
   - **DO NOT** make solid red/white filled circular play buttons.
   - **DO NOT** change the appearance or structure of `TransportButton.qml` unless explicitly requested by the user.

2. **Button Consistency**:
   - Use `TransportButton.qml` consistently across MiniPlayer, Main Window bottom dock, card hovers, and section headers.
